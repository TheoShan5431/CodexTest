# 一刻 · 番茄钟

一个用原生 HTML、CSS 和 JavaScript 编写的独立番茄钟项目。无需安装依赖，也无需服务器。

## 运行

下载并解压仓库后，双击本目录中的 `index.html`，即可在现代浏览器中使用。

## 功能

- 专注、短休息、长休息三种模式，默认分别为 25、5、15 分钟。
- 开始、暂停、继续、重置计时；切换模式会停止并重置当前计时。
- 每种模式可设置为 1–120 的整数分钟。保存设置不会改变当前轮次，切换模式、重置或下一轮时使用新时长。
- 完整完成一轮专注后，累计今日完成次数与专注分钟数。暂停、提前重置、未完成或休息不会计入。
- 完成后手动选择下一轮；每次打开页面累计完成 4 轮专注时，建议长休息，其余建议短休息。不会自动开始计时。
- 当前日期按浏览器本地时区计算。专注按本轮截止时间所在日期入账；即使页面次日才恢复，也不会把前一天已结束的专注计到今天。统计只保留最近一次有完成记录的日期，页面显示今天的数据。
- 设置和统计存于当前浏览器的 `localStorage`；不可用时提示并降级为内存保存。
- 手机适配、键盘操作、计时状态与完成提示的屏幕阅读器支持。
- 无外部依赖、网络请求、声音、系统通知或登录认证。

## 计时与后台行为

运行时通过“结束时间减当前时间”计算剩余时长，每约 250 毫秒刷新显示，而不是逐次减去固定秒数。浏览器延迟执行后台定时器时，重新获得执行机会会按结束时间校正，并且只为当前轮次记录一次完成。

电脑休眠或浏览器冻结时无法保证准时提示。页面恢复执行后会校正时间；完成后的下一轮仍需手动开始。手动调整系统时间也会影响剩余时长。

**运行中的计时不保存。** 刷新、关闭页面或浏览器终止页面后，重新打开会从完整专注时长待开始，不补记未记录的专注。若需要准确记录，请保持页面打开，并等待完成状态出现。多个标签页的统计独立运行，可能互相覆盖保存的数据，建议仅打开一个计时页面。

## 本地数据

- 设置键：`codextest.pomodoro.settings.v1`
- 今日统计键：`codextest.pomodoro.stats.v1`

清除浏览器数据会清除这些设置和统计，不同浏览器、设备或页面地址之间不会同步。`file://` 页面的本地存储行为由浏览器决定；隐私模式、禁用存储或空间不足时可能无法持久保存。

## 文件结构

```text
pomodoro/
├── index.html   # 页面结构和控件
├── styles.css   # 暖色样式、计时圆环和手机布局
├── app.js       # 计时状态、设置、今日统计与本地存储
└── README.md    # 使用说明
```

本项目是前端学习 Demo，适合在此基础上练习页面样式、事件处理和本地数据读写。
