# 落子 · 五子棋

双击 `index.html` 即可在现代浏览器中开始本机双人对局，无需安装依赖。

- 15 × 15 棋盘，黑棋先行，双方交替落子。
- 横、竖、两条斜线任意方向连续五子及以上获胜，无禁手。
- 禁止重复落子，胜负确定后停止落子；满盘无人获胜则和棋。
- 支持单步悔棋（含结束后撤回）、重新开始及最后一手和获胜连线标记。
- 方向键移动焦点，Enter 或空格落子；适配手机屏幕。
- 棋局只在当前页面内存中保存，刷新即重置。无 AI、联网对战或外部请求。

可选：在仓库根目录执行 `python3 -m http.server 8000`，再在浏览器中访问该服务的 `/gomoku/` 页面。
