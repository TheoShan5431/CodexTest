## 小步 · 今日清单

一个适合开始 GitHub 旅程的小项目：用原生 HTML、CSS 和 JavaScript 编写的中文待办清单。无需安装依赖，也无需服务器。

## 运行

1. 下载本仓库（GitHub 页面点击 **Code → Download ZIP**），并解压。
2. 使用现代浏览器双击打开 `index.html`。
3. 添加一件小事，试试完成、删除和筛选功能。

也可以克隆仓库后直接打开 `index.html`。首次打开会显示三条示例事项，你可以自由修改或删除。

## 功能

- 添加事项，每项最多 160 个字符，支持按 Enter 提交。
- 标记完成、恢复待办、删除单项、清除全部已完成事项。
- 按全部、进行中、已完成筛选。
- 显示完成进度和剩余数量，提供对应的空状态。
- 通过 `localStorage` 在当前浏览器保存清单。
- 适配手机和桌面，支持键盘操作和屏幕阅读器状态提示。
- 无外部字体、第三方依赖或网络请求。

## 数据如何保存

所有数据仅保存在当前浏览器的 `localStorage`，存储键为 `hello-github-demo.tasks.v1`。浏览器不会向 GitHub 或其他服务器提交清单内容。

清除浏览器数据会删除已保存的清单。不同浏览器、设备、浏览器配置文件或打开地址不会自动同步数据。浏览器对 `file://` 页面的本地存储支持可能不同；隐私模式、禁用存储或空间不足时，页面会提示当前修改仅临时保存，刷新或关闭后可能丢失。

这是一个前端演示项目，**没有注册、登录、身份认证、服务端或数据库**，也不使用密码、API 密钥或令牌。请使用普通示例内容，不要把清单当作敏感信息的安全存储。

## 代码导览

`app.js` 从本地存储读取清单并检查数据格式；表单和按钮事件修改内存中的任务数组，再保存并重新渲染页面。任务内容通过 `textContent` 写入页面，不会作为 HTML 执行。筛选只改变显示内容，不会删除隐藏的任务。

想做第一个修改，可以从 `styles.css` 的 `:root` 配色开始，或者修改 `app.js` 中 `sampleTasks()` 的示例事项。
